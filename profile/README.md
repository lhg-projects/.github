## 命名约定

- 仓库、技能、插件：`lls-` 前缀，全部收敛到同一个命名空间。
- 产品对外用中文名，机器可读的地方用 ASCII 短名。例：`刘老师 · 录课台` / `LLSStudio`。
- 完整约束见 [`lls-handbook`](https://github.com/lhg-projects/lls-handbook)。
